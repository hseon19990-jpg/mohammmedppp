حزمة تحديث أوامر بوت تيليجرام

محتويات الحزمة:
- bot.py: نسخة كاملة معدّلة تتضمن /start و /buy.
- telegram-start-buy-commands.patch: التغييرات كملف patch للتطبيق على نسخة المصدر المطابقة.

طريقة الاستخدام المفضلة إذا كان لديك تعديلات محلية أخرى: انسخ ملف patch إلى جذر المستودع ثم نفّذ:
git apply telegram-start-buy-commands.patch

يمكنك بدلًا من ذلك استبدال bot.py بالنسخة المرفقة، لكن خذ نسخة احتياطية أولًا؛ استبدال الملف الكامل قد يستبدل أي تعديلات محلية أخرى.
لا تستخدم الاستبدال الكامل وملف patch معًا.
